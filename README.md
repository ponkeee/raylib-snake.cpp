# raylib-snake.cpp
### A snake game made with raylib and C/C++

Completely inefficient and full of spaghetti code but eh, I'm still learning and on my way getting better


# Compiling
for compiling on a linux device assuming you have the raylib library installed in your device and its headers in the */usr/include* directory
Using GCC
```g++ snake.cpp -o snake -lraylib```
